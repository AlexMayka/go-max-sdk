## 📖 Как читать документацию

### Соглашения

**Примеры кода:**
```go
// Комментарий объясняющий код
bot.OnCommand("/start", func(ctx *BotContext) {
    ctx.Reply("Привет!")
})
```

**Таблицы параметров:**
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `MaxWorkers` | `int` | 20 | Количество воркеров |

**Рекомендации:**
- ✅ **Хорошо** - правильный подход
- ❌ **Плохо** - неправильный подход
- ⚠️ **Внимание** - важная информация

### Уровни сложности

🟢 **Базовый** - для начинающих
🟡 **Средний** - требует опыта
🔴 **Продвинутый** - для экспертов

## 💡 Полезные советы

### Отладка
```go
// Включите логирование для отладки
bot.Logging = true

// Или используйте кастомный логгер
bot.Logger = &MyLogger{}
```

### Тестирование
```go
// Используйте test токен для разработки
bot := maxsdk.NewBot("test-token")
bot.Config.APIRateLimit = 1.0  // Медленнее для тестов
```

### Производительность
```go
// Настройте под вашу нагрузку
bot.Config.MaxWorkers = 50        // Больше воркеров
bot.Config.APIRateLimit = 30.0    // Выше лимит
```

## 🆘 Получение помощи

### Частые вопросы

**Q: Как обработать команду с параметрами?**
A: Используйте `OnRegex()` - см. [handlers.md](handlers.md#onregex)

**Q: Как сохранить данные между сообщениями?**
A: Используйте FSM данные - см. [context.md](context.md#setdata)

**Q: Как настроить производительность?**
A: Смотрите [config.md](config.md)

**Q: Бот работает медленно, что делать?**
A: Увеличьте `MaxWorkers` и `APIRateLimit` в конфигурации
