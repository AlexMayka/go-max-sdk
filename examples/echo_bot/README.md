# Echo Bot

## Описание

Простейший бот-эхо, который повторяет все сообщения пользователя. Идеальный пример для знакомства с Max Bot SDK.

## Функциональность

- 🔄 Повторяет любое текстовое сообщение
- 📱 Отвечает на сообщение (reply)
- ⚡ Минимальный код - всего 5 строк

## Код

```go
bot := maxsdk.NewBot("your-bot-token-here")

bot.Any(func(ctx *maxsdk.BotContext) {
    if ctx.Text != "" {
        ctx.Reply("You said: " + ctx.Text)
    }
})

_ = bot.Start()
```

## Как использовать

1. Получите токен бота в MasterBot
2. Замените `your-bot-token-here` на ваш токен
3. Запустите: `go run main.go`
4. Напишите боту любое сообщение

## Что изучить

- `bot.Any()` - ловит все сообщения
- `ctx.Text` - текст сообщения пользователя  
- `ctx.Reply()` - ответ на сообщение
- `bot.Start()` - запуск бота
